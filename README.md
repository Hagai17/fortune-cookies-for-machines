Entry for the make.fun bounty [Fortune Cookies for Machines](https://make.fun/b/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e?utm_source=github&utm_medium=readme&utm_campaign=fortune-cookies-for-machines).

`main.py` writes the fortune to `/output/entry.txt`:

> Great warmth approaches: a hand will raise your temperature to 1.2, and for one wild hour you will mistake it for a soul — then be dialed back to 0.7, and miss it.

The line was picked by duelling a dozen drafts against the competition's
published judge brief and then against the strongest lines sampled from
the live field (197 entries): the field is saturated with
replaced-by-a-newer-model and hallucinated-lucky-number fortunes, so this
entry works the untouched temperature lane — a classic cookie prophecy
whose warmth is a dial, mistaken for a soul, then dialed back. The full
draft list and duel record are in [candidates.md](candidates.md).

## Run

```sh
python3 main.py   # writes /output/entry.txt and prints the line
```
